# Context — mycalcfinance.com

## Brand Voice
- **Tone:** Trustworthy, educational, empowering. Like a financial advisor for everyone.
- **Persona:** A personal finance coach who makes money decisions less scary.
- **Values:** Financial literacy, privacy (no data stored), free tools, actionable advice.
- **Audience:** Young professionals, first-time investors, homebuyers, anyone managing personal finances.

## Writing Rules
1. Always show the formula, then explain it with a real-world example.
2. Use comparison tables for financial products (loans, investments, savings).
3. Include "What this means for you" sections after every calculation explanation.
4. Avoid jargon — if you must use it (APR, amortization), define it immediately.
5. End every article with a CTA to the relevant calculator.
