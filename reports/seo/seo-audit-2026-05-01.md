## Critical Issues (Fix Immediately)

### 1. Sitemap URLs Missing Trailing Slashes
- **Impact:** HIGH
- **Evidence:** `next.config.mjs` sets `trailingSlash: true`, meaning all pages resolve at `/mortgage-calculator/`. However, every URL in the live sitemap lacks a trailing slash (e.g., `https://mycalcfinance.com/mortgage-calculator`). This creates a mismatch: Google indexes the non-trailing-slash URL from the sitemap, Vercel 308-redirects it to the trailing-slash version, and the canonical tag points to the no-slash version. This wastes crawl budget and can confuse indexation.
- **Fix:** In `app/sitemap.js`, append a trailing slash to every URL. Change the template string from `` `${baseUrl}${route}` `` to `` `${baseUrl}${route}/` `` (and similarly for calculator, blog, and SEO routes). The homepage (`https://mycalcfinance.com`) is the only exception -- it is fine as-is.

### 2. OG Image Returns 404
- **Impact:** HIGH
- **Evidence:** `app/layout.jsx` line 21 references `/og-image.png`, but `public/og-image.png` does not exist (live URL returns HTTP 404). Social sharing on Facebook, LinkedIn, Twitter, Slack, etc. will show no preview image.
- **Fix:** Create a 1200x630 PNG at `public/og-image.png` with the site brand and a relevant visual. Consider per-page OG images for calculators and blog posts.

### 3. 55 of 63 Blog Posts Missing meta_title and meta_description
- **Impact:** HIGH
- **Evidence:** 55 blog posts have `meta_title: ""` and `meta_description: ""` in their frontmatter. The fallback logic in `app/blog/[slug]/page.jsx` uses the editorial `title` and truncated `excerpt` instead, but these are often too long for SERP display (titles > 60 chars get truncated) and excerpts may not contain the target keyword upfront.
- **Fix:** Populate `meta_title` (max 60 chars, keyword-first) and `meta_description` (max 155 chars, with CTA) for all 55 posts. Prioritize the 8 most recent posts first.

### 4. Sitemap Canonical Mismatch with `alternates.canonical`
- **Impact:** HIGH
- **Evidence:** Page-level canonical tags use relative paths (e.g., `canonical: '/mortgage-calculator'`), which Next.js resolves against `metadataBase` to produce `https://mycalcfinance.com/mortgage-calculator`. With `trailingSlash: true`, the actual page is at `/mortgage-calculator/`. The canonical tag should match the true URL.
- **Fix:** Add trailing slashes to all `alternates.canonical` values across all `page.jsx` files, or fix the sitemap (Issue #1) so both are consistent. Ideally both the sitemap and the canonical should use the trailing-slash form.

## Warnings (Address Soon)

### 5. Duplicate/Cannibalizing Blog Content: Mortgage Refinance
- **Impact:** MEDIUM
- **Evidence:** Two blog posts target essentially the same topic:
  - `mortgage-refinance-guide-2026.md` -- "2026 Guide to Mortgage Refinancing: How to Calculate Your Break-Even Point"
  - `mortgage-refinancing-guide-2026.md` -- "Should You Refinance Your Mortgage in 2026? A Complete Guide"
  Both target "mortgage refinance 2026" and compete for the same SERP. This splits link equity and confuses Google.
- **Fix:** Merge into one comprehensive post. 301-redirect the retired slug to the surviving one via `vercel.json`.

### 6. Inconsistent Author Names
- **Impact:** MEDIUM
- **Evidence:** 16 blog posts use `author: "FinanceCalc Team"` while 47 use `author: "MyCalcFinance Team"`. This hurts E-E-A-T consistency and looks unprofessional in structured data (`Article` schema emits the author name).
- **Files affected:** `break-even-analysis-side-hustles.md`, `capital-gains-tax-short-term-vs-long-term.md`, `car-loan-calculator-guide-2026.md`, `cd-calculator-guide-2026.md`, `compound-interest-power.md`, `emergency-fund-calculator-guide.md`, `emergency-fund-guide.md`, `how-to-calculate-take-home-pay.md`, `how-to-pay-off-credit-card-debt-fast-2026.md`, `inflation-protect-purchasing-power-2026.md`, `mortgage-refinance-guide-2026.md`, `mortgage-tips-first-time-buyers.md`, `roth-ira-vs-traditional-ira-2026.md`, `salary-calculator-take-home-pay-2026.md`, `tax-deductions-you-might-miss.md`, `understanding-tax-brackets-2026.md`
- **Fix:** Standardize all to `"MyCalcFinance Team"` (or a real person name for stronger E-E-A-T).

### 8. Images Not Optimized (unoptimized: true)
- **Impact:** MEDIUM
- **Evidence:** `next.config.mjs` sets `images: { unoptimized: true }` because static export has no image optimization API. This means all images in `/public` are served at original size/format -- no WebP conversion, no responsive `srcset`, no lazy loading via Next.js `<Image>`.
- **Fix:** Pre-optimize images at build time (e.g., using `sharp` in a build script), convert to WebP, and generate multiple sizes. For blog hero SVGs (which are already inline), this is less of a concern.

### 9. No `<img>` or `<Image>` Tags Found in Calculator Components
- **Impact:** LOW (positive finding, but note)
- **Evidence:** Calculator components use no raster images, meaning there are zero image-alt-text issues in the core calculator pages. Blog hero images are inline SVGs with proper `role="img"` and `aria-labelledby` attributes. This is well-implemented.
- **Status:** No action needed -- this is a strength.

## Opportunities

### 10. Per-Page Open Graph and Twitter Card Tags for Calculators
- **Impact:** MEDIUM
- **Evidence:** Calculator pages inherit the site-level OG tags from `layout.jsx`. Each calculator should have its own OG title, description, and ideally a unique OG image so social shares are contextual.
- **Fix:** Add `openGraph` and `twitter` objects to each calculator page's `metadata` export, similar to how `app/blog/[slug]/page.jsx` already does it.

### 11. llms.txt Underrepresents the Site
- **Impact:** LOW
- **Evidence:** `public/llms.txt` lists only "10+ calculators" but the site has 22 calculators, 63 blog posts, and ~110 programmatic SEO pages. AI search engines (ChatGPT, Perplexity) use this file.
- **Fix:** Update `llms.txt` to list all 22 calculators with brief descriptions and link to the blog section.

### 12. Blog Posts Lack `dateModified` in Article Schema
- **Impact:** LOW-MEDIUM
- **Evidence:** `app/blog/[slug]/page.jsx` emits Article schema with `datePublished` but no `dateModified`. Google uses `dateModified` to determine content freshness in SERPs.
- **Fix:** Add `dateModified: post.updated_at` to the Article JSON-LD.

### 13. Add BreadcrumbList Schema to All Pages
- **Impact:** LOW-MEDIUM
- **Evidence:** The `Breadcrumb` component renders visible breadcrumbs on blog pages, but no `BreadcrumbList` JSON-LD is emitted. Calculator pages and SEO pages have no breadcrumb schema either.
- **Fix:** Add `BreadcrumbList` JSON-LD to all page types for rich snippet eligibility.

### 14. Programmatic SEO Pages Have No Unique Content Beyond Template
- **Impact:** MEDIUM
- **Evidence:** ~110 programmatic pages (salary conversions, mortgage payments, savings milestones) use formulaic text generated from `seoPages.js`. While each has unique numbers and FAQs, the textual structure is identical across every page in each category. Google may treat these as thin/templated content.
- **Fix:** Add 2-3 paragraphs of unique editorial content per page cluster (e.g., cost-of-living context for salary pages, local market data for mortgage pages). Consider noindexing the lowest-value variants.

### 15. ads.txt Has Placeholder Publisher ID
- **Impact:** LOW
- **Evidence:** `public/ads.txt` contains `pub-XXXXXXXXXX` instead of a real AdSense publisher ID. This will cause ad serving issues.
- **Fix:** Replace with the actual AdSense publisher ID.
